# Ollama Document Q&A and Summarization Project

This project uses **Ollama** and a **local Large Language Model (LLM)** to:
- Answer user questions
- Read and summarize documents (including images like invoices)
- Run fully **offline** using locally hosted models

The goal is to provide a lightweight, private, and fast alternative to cloud-based LLM APIs.

---

## 🚀 Features

- ✅ Ask questions using a local LLM
- ✅ Summarize text documents
- ✅ Summarize images (e.g. invoices, receipts) using vision models
- ✅ No internet required after model download
- ✅ Simple Python interface
- ✅ Easy to extend with FastAPI or a frontend

---

## 🧠 Models Used

- **Text-only models**
  - `llama3` (Q&A, summarization)

- **Vision models**
  - `llava` (image understanding and summarization)
